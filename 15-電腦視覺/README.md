# 👁️ 電腦視覺

處理影像與相機幾何的工具：可微分的影像處理、相機模型與多視角幾何、特徵偵測與匹配，以及訓練用的資料增強。讓 AI 理解物理空間、控制機器人的工具見 [🤖 機器人與具身智慧](../01-機器人與具身智慧/)；OCR 與影像生成模型見 [🧩 模型](../10-模型/)。

## 視覺函式庫

### [Kornia](Kornia.md)

建立在 PyTorch 上的可微分電腦視覺函式庫：超過 1,200 個運算子，涵蓋濾波、色彩、相機模型、對極幾何、PnP、RANSAC、特徵偵測與匹配（LoFTR、LightGlue 等）與資料增強，可整批在 GPU 上執行，大多能反向傳播梯度。官網定位是「機器人與空間 AI 的電腦視覺」。最新版 v0.9.0（2026-10）。Apache-2.0。⚠️ 只有整批 GPU 運算才比 OpenCV 快；半精度支援不完整。

可以做到：
- 在 GPU 上整批做相機標定、立體視覺、位姿估計與影像對位。
- 對深度、位姿、相機參數求梯度，用在自監督深度或位姿學習。
- 讓影像、遮罩、框、關鍵點一起做資料增強，或匯出成 ONNX。

## 怎麼挑

- 需要**在 GPU 上做可微分的影像處理與幾何視覺**（相機模型、位姿、特徵匹配、資料增強）：Kornia。單張圖、CPU 上的一般影像處理，OpenCV 仍較快。
- 想讓 **VLM 呼叫感知工具回答空間問題**：見機器人類的 [SpatialClaw](../01-機器人與具身智慧/SpatialClaw.md)。
- 要**辨識文件文字**：見模型類的 [Indra OCR](../10-模型/Indra-OCR.md)。
